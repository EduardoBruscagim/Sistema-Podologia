# RTK - Rust Token Killer

Always prefix terminal/shell commands with `rtk` to minimize token consumption.

Examples:

- `rtk git status`
- `rtk git diff`
- `rtk git log -n 5`
- `rtk git add .`
- `rtk git commit -m "..."`
- `rtk npm test`
- `rtk npm run check`
- `rtk cargo test`
- `rtk find ...`
- `rtk grep ...`
